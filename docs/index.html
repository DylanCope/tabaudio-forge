TabAudio Forge

TabAudio Forge

Record audio from the active browser tab and save it locally.

Install View on GitHub

Features

Tab Audio Capture

Record sound from the current browser tab with one click.

Pause & Resume

Control the session without losing captured data.

Local Save

Downloads a WebM file directly to your computer.

No Telemetry

No accounts, no ads, no analytics, no network requests.

Install

  1. Open chrome://extensions or edge://extensions.

  2. Enable Developer mode.

  3. Click Load unpacked and select this repository folder.

  4. Open a tab with audio, click the extension icon, and press Start.

Privacy

Audio is processed entirely on your device. Nothing is uploaded. The extension does not initiate any network requests.
